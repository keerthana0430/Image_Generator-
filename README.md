# Image_Generator-
AI Image Generator
• An AI Image Generator built using Python, Streamlit, and Hugging Face Diffusers. • Enter a text prompt and generate an AI-generated image.

Features
• Enter a text prompt • Generate AI images • Text-to-image generation • Powered by Stable Diffusion • Simple Streamlit interface • AI-generated image display

Technologies
• Python • Streamlit • PyTorch • Hugging Face Diffusers • Transformers • Stable Diffusion

Project Structure
AI-Image-Generator/
├── imagegenerator.py
├── requirements.txt
└── README.md
Run the App
• streamlit run imagegenerator.py

Usage
• Open the Streamlit application. • Enter a description of the image you want to create. • Click Generate Image. • Wait for the AI model to process the prompt. • View the generated image.

Example
Prompt: A cute cat sitting in a beautiful garden

Output: The AI model generates an image based on the given text prompt.

Model
Uses a pretrained Stable Diffusion model from Hugging Face:

stabilityai/stable-diffusion-2-1-base

Key Learning
• Generative AI • Text-to-Image Generation • Stable Diffusion • Hugging Face Diffusers • PyTorch • Streamlit Web Applications • Pretrained AI Models
